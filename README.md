# Задушевный книжный

Контрольная работа №1 по дисциплине «Фронтенд и бэкенд разработка».
Тема: «HTML и CSS: разработка многостраничного сайта».

## Описание проекта
В проекте реализован многостраничный сайт книжного магазина. Сайт разработан только с использованием HTML и CSS, без сторонних фреймворков.

## Ссылка на опубликованный проект
GitHub Pages: https://aleconick.github.io/kr1-html-css-shop.html

## Страницы проекта
- index.html — Главная страница (hero-блок, преимущества, популярные книги).
- catalog.html — Каталог книг (карточки, блок фильтров).
- product.html — Страница книги (описание, таблица характеристик, кнопка заказа).
- order.html — Форма оформления заявки.
- contacts.html — Контакты и форма обратной связи.

## Используемые технологии
- Семантическая разметка: header, nav, main, section, article, aside, footer.
- Стилизация: CSS3, CSS-переменные (:root), Flexbox, CSS Grid.
- Методология: БЭМ (Блок, Элемент, Модификатор).
- Интерактивность: минимальный JavaScript для работы модального окна.
- Позиционирование: relative, absolute, fixed, sticky, z-index.
- Доступность: состояния :hover и :focus-visible.

## Самостоятельные доработки
1. Собственный визуал.
2. Каталог наполнен любимыми книгами.
3. Добавлена фиксированная кнопка «Наверх».
4. Реализовано расширенное модальное окно для быстрого заказа (имя, телефон, email, комментарий, согласие).
5. Использованы БЭМ-модификаторы для бейджей («Хит», «Новинка»).
6. Настроена адаптивная сетка для мобильных устройств.
7. Внедрены обложки книг.
